# E47.9 — Recuperación H05: impedir reintento después de DONE no asentado

## Decisión aprobada

Esta TASK es una recuperación mecánica de E47.8. No introduce una decisión nueva.

E47.8 aprobó explícitamente que:

- una corrida inicial FAILED puede reintentarse;
- una corrida inicial DONE NO puede reintentarse;
- no puede existir doble llamada/costo por una ventana de estado;
- H03 debe seguir cerrado.

La auditoría de ChatGPT encontró que `start_create()` valida `status(case)` antes de ejecutar `settle(case_id)`. Si la corrida previa ya terminó DONE pero todavía no fue asentada como `pipeline`, el estado inicial sigue pareciendo CAPTURED; `settle()` asienta el DONE, pero después no se revalida el estado y se puede crear otra corrida inicial.

## Problema

Secuencia defectuosa actual:

1. existe `create_started`;
2. la corrida subyacente termina DONE;
3. todavía no existe el evento `pipeline`;
4. llega otro POST a procesar;
5. `status(case)` se evalúa antes de `settle()` y permite continuar;
6. `settle()` registra el DONE;
7. `_unsettled_create()` ya da false;
8. se obtiene un claim nuevo y `_begin_create()` puede crear otra corrida/potencial costo.

Después, al intentar asentar esa segunda corrida, `record(..., "pipeline")` rechaza porque ya existe un DONE, dejando además una inconsistencia operacional.

Esto viola E47.8 AC5 y la invariancia de no doble costo.

## Resultado esperado

Corregir exclusivamente la ventana de estado encontrada por la auditoría:

- `settle(case_id)` debe ocurrir antes de tomar la decisión final de si un CREAR puede lanzar una nueva corrida inicial, o debe existir una revalidación equivalente inmediatamente después;
- si el intento previo terminó DONE, el mismo request debe terminar rechazado antes de `runs.create_initial`;
- si el intento previo terminó FAILED, el mismo request debe poder seguir al reintento legítimo;
- si sigue pendiente, debe seguir rechazándose;
- conservar el claim atómico de E47.3/E47.8;

- añadir el espejo FAILED no asentado → segundo POST → retry permitido, para evitar arreglar un lado rompiendo el otro.
