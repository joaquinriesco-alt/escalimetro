**VIVAN LOS PLANOS.**

North Star aprobado:

> **PLANOS QUE AYUDAN A VENDER.**
>

Secuencia de producto aprobada:

**PLANO EXISTENTE → PLANO CORPORATIVO → CABIDA → LAYOUTS → VISUALIZACIÓN OPCIONAL**

Prioridad de producto:

1. **Plano Corporativo** — el cliente ya tiene un plano; ESCALÍMETRO lo vuelve limpio, atractivo,
   corporativo, fácil de entender, consistente y publicable.
2. **Crear Plano Comercial** — si no existe un plano útil, usar la información disponible para
   producir una planta comercial clara y útil; no presentarla como levantamiento exhaustivo.
3. **ESCALÍMETRO PRO / Layouts** — **PLANTA + PROGRAMA → alternativas de cabida/layout** para
   demostrar rápidamente cómo podría funcionar un prospecto dentro de una oficina.

Staging, renders, video, scoring y otras visualizaciones pueden existir después, pero son
complementos del plano y no el centro.

Regla de producto:

**¿Esto hace que el plano ayude más a vender o entender el potencial del espacio?**

Si no, probablemente no pertenece al core.

oficina.

contra el North Star para evitar implementar otra dirección que inmediatamente haya que deshacer.
