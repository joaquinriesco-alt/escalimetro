## Metricas congeladas
TARGET_ONLY   : balanced accuracy, abstention rate.
FULL_CONTEXT  : balanced accuracy, recall enclosure, recall furniture, abstention rate,
                confusion matrix 2x3.
Comparacion   : DELTA_BA = BA_SINGLE - 0.764 ; cambio por clase ; cambio de abstencion.
Bootstrap     : 10.000 remuestreos, unidad = EL PAR. IC95 de BA_FULL_CONTEXT, del improvement
                SINGLE vs TARGET_ONLY, y del DELTA SINGLE vs E19 batch=6.
AMBIGUOUS cuenta como abstencion, nunca como acierto.
No se calibra confidence. No se crean thresholds post-hoc.
El scoring de TARGET_ONLY conserva la regla de E19: una respuesta por par, puntuada contra las
dos verdades del par.

## Gates congelados
A  SINGLE-IMAGE CONTEXT REPLICATION STRONG
   BA_FULL_CONTEXT >= 0.80  AND recall enclosure >= 0.70 AND recall furniture >= 0.70
   AND abstencion FULL_CONTEXT <= 0.10 AND limite inferior IC95 de BA_FULL_CONTEXT >= 0.70
   AND sin evidencia de contaminacion.
B  SINGLE-IMAGE CONTEXT REPLICATION PARTIAL — senal fuerte y consistente, falla al menos un
   gate de A.
C  BATCH EFFECT MATERIAL — |DELTA_BA| >= 0.10.
D  EXPERIMENT INVALID.
E  EXECUTION ENVIRONMENT LIMIT.

Nota: A y C no son excluyentes por construccion; si ambos se cumplieran, el informe declara
